77 GHz radar MMIC · design for test

On-chip BIST and loopback: testing a 77 GHz radar without 77 GHz instruments

How a radar MMIC generates its own test stimulus, routes it through loopback paths, measures the result with its own ADCs and counters, and feeds the numbers back as pass/fail results, eFuse trims and calibration tables. The aim is to move production test from an RF ATE with mmWave instruments to a low-cost digital/DC tester running many sites in parallel, and to reuse the same hardware as ISO 26262 safety monitors in the field.

Why BIST: what it replaces

Testing a 77 GHz transceiver the conventional way needs mmWave power meters or spectrum analysers per Tx, a calibrated 77 GHz source and noise source for the Rx, frequency-extension heads, and an RF-capable load board. Each channel is measured one after another, with instrument settling and switching in between. The equipment is expensive, needs calibration, is hard to run multi-site, and in practice takes up most of the test time.

With BIST the chip is its own instrument. The ATE only supplies power, a reference clock and a digital interface (SPI/I²C, GPIOs). It loads a test firmware, starts a test list, and reads back results the chip has already computed.

02

Generating stimulus on-chip

The FMCW loopback problem, and the fix

In FMCW, Tx and Rx use the same chirping LO. A straight Tx → Rx loopback has almost zero delay, so its beat frequency is about S·τ ≈ 0 Hz: it lands at DC and the HPF removes it. A useful loopback therefore has to be offset in frequency by a known f_m (typically 0.5–5 MHz), so that it appears as a clean tone in a chosen IF bin. The same fact is also useful: loopback leakage when the path is "off" also lands at DC, where it is harmless.

Level plan for loopback B (typical)

P_Tx out +12 dBm Tx output coupler (weak) −20 dB ← costs ≈0.05 dB of Pout Programmable attenuator −0 … −30 dB Modulator loss (SSB / BPSK 1st) −4 … −6 dB Rx input coupler −20 dB ← adds ≈0.2–0.4 dB to NF ───────────────────────────────────────────── At LNA input ≈ −34 … −64 dBm (well below Rx P1dB ≈ −10 dBm)

Set the attenuator so the tone sits about 10–20 dB below ADC full scale. The ratio of tone to noise in one FFT bin is then 50–70 dB, so a single chirp is enough for gain and phase accuracy better than 0.05 dB / 0.3°.

03

Measuring on-chip: four instruments in silicon

1 · Power detector + aux ADC

A square-law (diode-connected MOS or bipolar) or log detector sits on a weak coupler at the PA output. Its DC output is proportional to RF power and goes to a 10–12 bit SAR ADC through the analog mux. A second detector on the reverse port measures reflected power.

V_det = V_off + k · P_RF (square-law region) P_out[dBm] = 10log((V_on − V_off)/k) + C_cpl Differential: V_off = V_det with PA off → removes offset/drift

Always measure PA on minus PA off, and ratio against an on-chip reference voltage, so that offset and ADC gain errors cancel.

2 · Main Rx ADC + FFT as a vector receiver

The normal Rx chain acts as a vector network analyser receiver. Pick f_m so it falls exactly on a bin (f_m = k·F_s/N) to avoid leakage between bins, and use a rectangular window.

X_i[k] = FFT(x_i)[k] channel i, tone bin k A_i = 2|X_i[k]| / N amplitude φ_i = arg X_i[k] phase ΔG_i = 20log(A_i/A_ref) relative gain Δφ_i = φ_i − φ_ref relative phase Noise = mean |X[j]|², j ≠ tone, harmonics, DC

3 · Frequency counter and PLL monitor

A prescaler divides the VCO (÷N, e.g. 256 at 20 GHz ≈ 78 MHz). A counter gated by the crystal counts it. The resolution at RF is set by the gate time:

f_RF = 4 · N · count / T_gate Δf_RF = 4 · N / T_gate T_gate = 1 ms → 1.0 MHz resolution at 77 GHz T_gate = 10 ms → 0.1 MHz

For slope and linearity during a chirp, read the PLL phase error (the ΣΔ loop error or TDC output in an ADPLL). Integrated frequency error along the ramp gives the RMS nonlinearity directly, without a counter.

4 · Aux ADC as DMM

The same aux ADC reads temperatures (PTAT diodes near each PA, digital, VCO), every supply rail through dividers, LNA and PA bias currents (through sense resistors), and a second bandgap. The two bandgaps checking each other is what makes the aux ADC trustworthy as a reference.

Resolution
10–12 bit, ≈1 mV LSB
Temp accuracy
±2–5 °C after 1-point trim
Conversion
≈1–5 µs per channel

Key recipes in detail

Rx gain & phase match (path B)

  1. Enable Tx1 at a fixed power code; enable the loopback, attenuator code for about −15 dBFS at the ADC.
  2. Start the SSB modulator at f_m = k·F_s/N (e.g. 1.25 MHz).
  3. Run a CW or shallow chirp. Capture N samples on all Rx at the same time.
  4. FFT; read X_i[k] for each Rx. Average 8–16 chirps for margin.
  5. ΔG_i, Δφ_i relative to Rx1 → write the calibration vector; compare with limits.

All Rx share one input signal and one LO, so the loopback's own variation cancels in the relative result.

Noise figure without a noise source

1. Known input tone P_in at LNA (from A + loopback cal) 2. G_total = P_tone,out − P_in (from FFT) 3. Disable loopback (input = 50 Ω, T0) 4. N_out = mean noise PSD in bins [dBFS/Hz → dBm/Hz] 5. NF = N_out − G_total − (−174 dBm/Hz)

Accuracy depends on the absolute value of P_in. Correlate it to lab NF on golden units, and track it with a guard band of about ±1 dB. With an on-chip hot/cold source, use Y = N_hot/N_cold, NF = ENR − 10log(Y−1).

Tx phase-shifter sweep

for code c = 0..63: set PS(Tx_n) = c ; capture ; X[k] φ(c) = arg X[k] − arg X_c=0[k] A(c) = |X[k]| / |X_c=0[k]| INL(c) = φ(c) − c · 5.625° → store corrected code map c' = argmin |φ(c) − target|

About 64 captures of 50 µs each is roughly 3 ms per Tx. On an RF ATE this would need a phase-coherent receiver on every Tx ball.

Chirp linearity (path D)

  1. Program the production chirp profile (slope, B, T_ramp).
  2. Stream the PLL phase error e[n] into memory during the ramp.
  3. Integrate to frequency error Δf[n]. Fit and remove a line to get the nonlinearity residual.
  4. Report RMS and peak residual (in kHz and % of B) inside the ADC window only, plus settling time after reset.

The counter (1 ms gate) checks the absolute start and stop frequency against the 76–81 GHz band edges.

Each measurement ends up in one or more of three places. The same code runs at wafer test, final test, module EOL and in the field.

Order matters. Trim the references first (bandgap → aux ADC → temperature sensor → power detector). Every later measurement depends on them, so a wrong bandgap trim makes every downstream result wrong in the same way.
06

Production flow on a low-cost tester

  1. Contact and DC: continuity, leakage, IDDQ, supply currents (ATE PMU).
  2. Digital: scan / ATPG, logic BIST, memory BIST (with repair if available), eFuse read.
  3. Boot test firmware over SPI into the RF control CPU's RAM; the ATE supplies the 40 MHz reference.
  4. Reference trims: bandgap and aux ADC (compare against one precision ATE voltage), temperature sensor (against the chuck or handler temperature).
  5. LO: VCO band calibration, lock, counter check of band edges, chirp linearity.
  6. Tx (A): power per Tx and gain code; reverse-power check with the load-board termination.
  7. Loopback (B, C, E): run all Rx in parallel: gain, phase, I/Q, NF, IF response, ADC SNR/SFDR, then the phase-shifter sweep.
  8. Burn eFuse, re-run a short verify subset, read the final result block. Bin.
  9. Hot/cold insertion: re-run the short list at temperature to fill the temperature LUT and catch drift outliers.

Where the test time goes

  • Most BIST measurements take µs to a few ms: one chirp capture plus an FFT.
  • All Rx measured at once; the Tx measured by switching, not by moving an instrument.
  • No instrument settling, RF switch matrix or GPIB/LAN transfers; only a short SPI readout of results.
  • Multi-site becomes easy: 8–32 sites need only digital pins, DC and a shared reference clock.
  • The rest is fixed overhead: FW download, eFuse burn, temperature soak. Compress the FW and burn eFuses on all sites in parallel.

Load board without RF instruments

  • Terminate each Tx ball in a matched load, which gives a known reflection for the reverse-detector test.
  • Optionally, a passive external loopback: a Tx ball → attenuator/trace → Rx ball on the load board. This also tests the balls, bumps and package transitions, which the on-chip loopback cannot see.
  • A longer trace gives a real delay τ, so a chirp produces f_b = S·τ; it checks slope end-to-end.
  • Keep one audit RF tester for sample-based correlation, not for every part.

Accuracy, correlation and coverage limits

BIST measures relative quantities very well (channel matching, steps, linearity, trends). Absolute quantities (Pout in dBm, NF in dB) inherit the uncertainty of an on-chip reference, such as the coupler, detector or noise-source ENR, which varies with process.

Rx/Tx relative gain±0.1–0.2 dBCoupler asymmetry between channelsSymmetric layout; one-time characterisation
Rx/Tx relative phase±1–2°Loopback routing length mismatchMatched routing; correction constants from design
Absolute Tx power±0.5–1 dBDetector slope and coupling spreadDetector trim; golden-unit correlation
Noise figure±0.7–1.5 dBAbsolute gain or ENR uncertaintyCorrelation + guard band; audit sampling
LO frequency≤ ref ppm + 1/T_gateCrystal accuracyUse the ATE's precision reference during test

Correlation and guard-banding

1. Characterise N_golden ≥ 30 units per lot corner on full RF ATE / bench 2. Fit true = a · BIST + b (per test, per channel), record residual σ 3. Test limit = spec limit ∓ (k·σ_residual), k ≈ 3 4. Ongoing: audit sample per lot on the RF tester; alarm on drift of b

What the loopback cannot see

  • Package and balls beyond the couplers: use the reverse detector against the load-board termination, or the passive external loopback.
  • Faults in the test circuitry itself: a broken loopback or a detector stuck at a plausible value. Add self-checks: loopback on vs off, detector with PA off must read offset only, both bandgaps must agree.
  • Common-mode faults: a shared LO fault affects the stimulus and the receiver equally and can cancel out in a ratio. Use the counter (D) as an independent check.
  • Spurious emission and absolute phase noise far from the carrier: cover them by design and characterisation, plus the PLL monitor. Measuring them in production would still need an instrument.
  • Antenna, radome, EIRP: tested at module EOL in a chamber, not at chip level.
08

DFT design checklist

RF / analog

  • Couplers weak enough: ≤ 0.1 dB Pout loss, ≤ 0.3 dB NF penalty
  • Loopback isolation when off > 60 dB (leakage lands at DC, but its harmonics may not)
  • Loopback attenuator range ≥ 30 dB to test from small signal to compression
  • Modulator f_m derived from the reference, bin-aligned to the ADC FFT
  • Detectors at matched positions on every Tx, with forward and reverse ports
  • Two independent bandgaps; aux ADC reference ≠ monitored reference
  • Noise source with stable ENR, or design for the cold method

Digital / firmware

  • Capture buffer for raw ADC samples of all Rx at once (≥ 1 chirp)
  • FFT accelerator reachable from the RF control CPU during test
  • PLL phase-error and counter readable at high rate
  • Test FW loadable over SPI, with limits and results in a compact table
  • eFuse burn + verify built into the FW; lockout after programming
  • Same monitor code reused in the field for the ISO 26262 safety mechanisms
  • Datalog format that includes the raw values, not just pass/fail, for correlation
The numbers are typical engineering values for RFCMOS radar MMICs and are meant for architecture planning. Actual accuracy depends on the implementation and must be established by correlation against calibrated RF measurements on characterisation lots.
