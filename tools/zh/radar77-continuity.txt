8e9b1a76 原因與做法：ESD 二極體法
4988d547 第一個測試
efb84b67 每個測試站（晶圓針測與最終測試）的第一批測試，會在施加任何電源<b>之前</b>，確認測試機確實連到每個腳位，且沒有任何腳位短路。晶片不上電。測試機每個腳位的 PMU 把小電流推進腳位，讀取腳位 ESD 保護二極體上的電壓。測試只需數毫秒，能抓到接觸不良、探針彎曲、錫球橋接與封裝開路，並保護元件與負載板免於在短路下上電。
bcbd3b9d 同一個焊墊以兩種極性測試。每次測試讓一個 ESD 二極體順偏，淡色的二極體為逆偏。(a) 負向：電流從 VSS 經 D_dn 上來，讀到 −V_f。(b) 正向：電流經 D_up 流入 VDD 電源，測試機把它保持在 0 V，讀到 +V_f。開路接觸在兩種極性下都沒有路徑，所以 PMU 會撞到箝位。對地或對 0 V 鄰腳短路時，兩種極性都讀到接近 0 V。
950a5e35 兩種極性的典型通過視窗。確切限值來自 ESD 二極體在各溫度下的特性量測（V_f 約下降 2 mV/°C，所以高溫針測讀值更接近零）。落在灰色保護帶內的讀值判為「邊緣」失敗，通常觸發重新接觸。
c6fdd1e6 如何執行兩種極性
abbe65b3 <b>電源接地：</b>測試機電源把每個 VDD 與 VSS 腳保持在 0 V（連接而非浮接），每腳 PMU 在其他所有訊號腳上施加 0 V。

238b2e91 有並聯的電阻性路徑（部分短路、漏電）：與保護帶及漏電測試比對
32ccd99a <b>為何兩種都要測？</b>只做負向測試就能證明有接觸。正向測試還會檢查上方 ESD 二極體，以及焊墊與 IO 電源環的連接。這能抓到搬運造成的 ESD 損傷，並以第二個獨立讀值確認短路。有些流程在晶圓針測時為了速度只做負向，最終測試才兩種都做。
e8e8bd72 <b>VDD 電源必須真的在 0 V。</b>若它浮接，正向電流會經 D_up 對晶片的電源去耦電容充電。讀值因此爬升並以不穩定或開路失敗，晶片也會經焊墊被部分反向供電。電流要小（≤ 100 µA），電源要接地。
41a429b1 <b>電源腳</b>另外檢查：做電源短路測試，再在 VDD 腳上加 −100 µA（VSS 為 0 V），讓電源箝位的本體二極體順偏，應讀到約 −0.65 V。

427dac9b 測試機如何辨認「Z」
dc60c4fc 每個測試機通道都有<b>主動負載</b>：可程式的電流源／汲，把沒被驅動的腳拉向門檻電壓 V_t（常為 VDDIO/2）。它也有帶 VOL 與 VOH 門檻的<b>視窗比較器</b>。正在驅動的腳會蓋過負載，讀到 0 或 1。真正關閉的腳被拉到兩門檻之間的 V_t，讀為 <b>Z</b>。
7c89febe 三態比較。主動負載電流（通常 0.1–1 mA）弱到任何致能的驅動器都能蓋過它，又強到能很快把真正關閉的腳拉到 V_t。

9bee8328 <b>使用 Cres 資料。</b>按 site 與每次下針記錄 Cres，而不只是通過／失敗。上升趨勢代表探針頭需要清潔，針測機可在接觸失敗變成良率損失前自動觸發線上清潔。「開路」失敗在重新接觸後重測一次，可把接觸問題與真正缺陷分開。追蹤恢復率，因為恢復率高指向探針卡而非晶圓。
